# dnsmgr v1051 完整迁移矩阵

本矩阵以原版 `route/app.php`、控制器和视图中的实际请求为功能基线。迁移完成的定义不是“存在一个可转发路径”，而是同时具备：

1. helper 中受控且可测试的上游操作；
2. 类型化读取/初始化接口；原版没有 JSON 入口时使用有测试保护的 v1051 页面状态解析；
3. 前端完整操作流程与权限处理；
4. 与原版行为一致的成功、失败和后台任务状态验证。

`src/adapters/v1051/operations.ts` 是服务端动作的机器可读白名单。页面初始化、HTML 状态解析和前端工作流由各功能适配器与独立前端补齐；不能把“存在白名单动作”等同于完成迁移。

## 验收规则

- 每个“已完成”条目必须同时有适配器测试和 HTTP 路由测试；仅列入动作白名单不能标记完成。
- 所有动态上游路径必须由固定模板生成，禁止任意 URL 或任意 dnsmgr 路径代理。
- 最终前端不得展示兼容层名称、实现方式或认证协议名称。
- UI 布局可参考 [shadcn-admin](https://shadcn-admin.netlify.app/) 与 [Shadcn UI Kit Dashboard Blocks](https://shadcnuikit.com/blocks?category=dashboard-ui)，CPA-Helper 只作为既有项目风格参考；控件结构、交互和可访问性优先遵循 shadcn/ui 官方示例。
- 亮色主题使用蓝色主色、白色与中性灰表面，不使用墨蓝色大面积背景；深色表面只用于暗黑模式。
- 原版公开 API 与后台执行入口必须单独验证，不能用浏览器会话接口的测试代替。
